I'm a Computer Science student exploring how AI agents can become more capable, reliable, and useful.

I'm especially interested in agents that do more than chat — systems that can plan, use tools, maintain context, learn from feedback, and operate over time. I enjoy following an idea from its earliest experiment to a complete, testable, and understandable system.

[**Read my blog →**](https://aries727.site)

## What I'm exploring

- Planning, reasoning, and tool use in autonomous agents
- Memory and context management for long-running tasks
- Human oversight, permission boundaries, and safe execution
- Evaluation, observability, and failure recovery
- Multi-agent interaction and persistent AI-driven environments
- Interfaces that make agents easier to understand and work with

## How I like to build

- **Start with the problem.** Technology is useful when it makes an idea clearer or a workflow better.
- **Build the whole system.** A promising prototype should also be testable, deployable, and maintainable.
- **Make autonomy observable.** Agents need visible state, meaningful logs, and understandable failure modes.
- **Keep humans in control.** Permissions and approval boundaries should be part of the product, not an afterthought.
- **Write things down.** Clear specifications and technical notes help both humans and agents work better.
